LAB SHEET 9 – FLUTTER REST API INTEGRATION AND JSON PARSING

Contains 15 separate Dart practical files (1.dart to 15.dart), following the
uploaded Lab Sheet 9 practical list.

Add this dependency to pubspec.yaml:

dependencies:
  flutter:
    sdk: flutter
  http: ^1.2.2

Then run: flutter pub get

For each Flutter practical, copy the required numbered file into lib/main.dart
of a Flutter project and run it on an emulator/device with internet access.
Practical 1 and 2 are standalone Dart console examples.

APIs used:
- https://jsonplaceholder.typicode.com
- https://fakestoreapi.com

Note: These are source examples and have not been run in your local Flutter
environment. Check package compatibility and test before submission.
