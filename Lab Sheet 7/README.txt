LAB SHEET 7 – FLUTTER SQLITE DATABASE PRACTICALS

This folder contains 17 separate Dart files, one for each practical.

IMPORTANT:
1. Create a Flutter project in Android Studio or VS Code.
2. Add these dependencies to pubspec.yaml:

dependencies:
  flutter:
    sdk: flutter
  sqflite: ^2.4.2
  path: ^1.9.1

3. Run: flutter pub get
4. Copy the required numbered .dart file into the project's lib/main.dart.
5. Run the app using an Android emulator or connected device.

Notes:
- Files 4, 6, 11, 12 and 17 are Flutter UI examples.
- Other files demonstrate database operations and print results to the debug console.
- All examples use a local SQLite database. The first practicals create the database/table as needed.
- These are separate practical source files, not one combined application.
- The code has not been executed in your local Flutter environment; check package compatibility with your installed Flutter version.
