LAB SHEET 8 – FLUTTER SQLITE PRACTICALS

This folder contains 17 separate Dart files: 1.dart to 17.dart.
Each file demonstrates one practical independently.

Required packages in pubspec.yaml:

dependencies:
  flutter:
    sdk: flutter
  sqflite: ^2.4.2
  path: ^1.9.1

Run flutter pub get after adding the packages.
To test one practical, copy that numbered file's code into lib/main.dart
of a Flutter project and run it on an Android emulator or device.

Note: These are source-code examples and have not been run in your local
Flutter environment. Test with your installed Flutter SDK before submission.
